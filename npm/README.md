# whyhot

Run the [`whyhot`](https://github.com/dunctk/whyhot) macOS heat diagnostic without installing Rust:

```sh
npx whyhot
```

Or install it globally:

```sh
npm install --global whyhot
whyhot
```

This package contains the official precompiled `whyhot` binaries for Apple Silicon and Intel Macs. It has no runtime dependencies, install scripts, telemetry, or binary downloads.

`whyhot` is read-only: it explains likely heat sources but never kills a process automatically.
